# 小小探索家 · 星瞳AI

给4-6岁小朋友做的一个自然探索小工具。用摄像头拍下身边的东西，AI认出来之后，讲一段小童话，还能顺便点亮图鉴。

项目参加传智杯 AI Web 赛道。

## 这个项目在干什么

小朋友（或者家长陪着）在页面上选一个任务，比如"寻找小狗"。然后打开摄像头拍一张，后端用 YOLO 判断照片里是不是任务里的东西。如果是，就让大模型讲一段童话故事返回，前端念出来；如果不是，会明确告诉小朋友"这张好像不是小狗"，让他重拍。

我们做这个的初衷其实很简单：现在大部分儿童 App 都是在屏幕里点来点去，孩子跟真实世界是隔开的。我们想让孩子抬起头、走出去，看见真的东西，同时 AI 能给一点回应，形成一个小闭环。
